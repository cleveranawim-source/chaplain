# Chaplain

기독교 학교 종교 과목 교과세부특기사항 초안 작성 도우미입니다.

## 기능

- 화면을 반 전체 생성 / 개별 학생 / 저장한 메모 탭으로 나눠 사용(마지막으로 연 탭 기억)
- 개별 학생 세특 초안 생성
- 종교 일반 카테고리 + 사회정서교육(정체성, 자기 발견, 회복탄력성, 공감 등) 주제 14종
- 주제별로 종교적 관점과 청소년의 삶·성장을 연결하는 설명 문장 자동 삽입
- 학년(1/2/3)별 차별화: 같은 주제라도 1학년은 기초 이해·호기심, 2학년은 연결·적용·심화, 3학년은 종합·주체적 해석 관점으로 서술
- 반 전체 생성 시 학년 지정: 파일 학년 열 자동 인식 또는 반 전체를 특정 학년으로 일괄 지정 선택
- 반 전체 엑셀 명단 업로드(학년 열 자동 인식: 1, 3학년, 고3, 3-5, 2학년 5반 등. 못 읽으면 폼 선택을 쓰고 표에 기본값으로 표시)
- 표 위에 제목 행이 있는 나이스 파일도 머리글 행(성명, 반/번호, 세부능력 및 특기사항 등)을 찾아 읽음
- CSV는 UTF-8과 한글 엑셀 기본 형식(EUC-KR) 모두 지원
- 파일의 단원 열이 있으면 그 값을 우선 사용(비슷한 이름은 앱의 단원으로 맞춤), 없는 학생에게만 체크한 주제를 배정
- 수행 강도는 선택한 값을 반 전체에 적용하고, 학생별로 다르게 하려면 파일의 '강도' 열(기본·안정·성장·강점·보완)을 사용(무작위 배정 없음)
- 학생별 주제, 활동, 강점, 문장 구조(도입·유형·강도·마무리) 분산 생성
- 일괄 생성 목표 글자수 지정(250~500자, 목표 +15자 이내)
- 중복 표현 검사(비슷한 문장 쌍, 반복 마무리)
- 나이스 기준 바이트 표시와 한도 초과 경고(한글 3, 영문·숫자·공백 1, 줄바꿈 2 · 최대 1,500바이트), 내면 신앙 평가 표현 점검
- 나이스에서 받은 원본 XLSX의 시트명·서식·구조를 그대로 유지한 채 세특 열만 채워 저장(나이스 재업로드 호환)
- 붙여넣기 작업 시에는 기본 양식의 XLSX로 저장
- 반 전체 생성의 'AI로 다듬기'(선택): 관찰 메모가 있는 학생만 업스테이지 Solar가 '반 공통 수업 내용 + 학생 메모'로 세특 문장을 다시 씀. 메모가 없는 학생은 기존 방식 그대로 두고 '메모 없음 · 검토 필요'로 표시
- 개별 학생 탭의 'AI로 다듬기'(선택): 관찰 메모와 체크한 강점을 바탕으로, 체크한 활동을 수업 맥락으로 삼아 한 학생의 세특 문장을 다시 씀

## 사용

`index.html` 파일을 브라우저에서 열거나 배포된 웹사이트에서 사용합니다. 입력한 내용은 브라우저 안에서만 처리되며, 'AI로 다듬기'를 직접 실행할 때만 아래 항목이 업스테이지로 전송됩니다.

## AI로 다듬기 설정

웹사이트(Vercel)에서만 동작합니다. `index.html`을 파일로 직접 열면 AI 기능은 꺼지고 나머지 기능은 그대로 쓸 수 있습니다. 탭 아래 'AI로 다듬기 설정'에서 **AI 모델**을 고르고 전송 동의, 접속 코드 또는 개인 API 키를 입력하며, 두 탭이 같은 설정을 씁니다. 고른 모델에 따라 "활동·관찰 내용이 ○○로 전송됩니다" 안내와 전송 동의 문구가 바뀌고, 모델을 바꾸면 동의를 다시 받습니다.

| AI 모델 | 필요한 것 | 사용료 |
| --- | --- | --- |
| Upstage Solar Pro 4 (학교 제공 · 기본) | 접속 코드(설정한 경우) | 학교(서버) 키 계정 |
| GPT-6 Luna (내 OpenAI 키) | `sk-`로 시작하는 OpenAI 키 | 선생님 본인 계정 |
| Claude Sonnet 5 (내 Anthropic 키) | `sk-ant-`로 시작하는 Anthropic 키 | 선생님 본인 계정 |

- **학교(서버) 키:** 관리자가 Vercel에 `UPSTAGE_API_KEY`를 등록해 두면 기본 모델로 쓸 수 있습니다. 등록하지 않으면 목록에 '학교 키 없음'으로 표시되고 고를 수 없습니다.
- **개인 키:** GPT나 Claude를 고르면 나타나는 칸에 키를 넣고 '적용'을 누릅니다. 고른 회사의 키가 아니면 거절합니다. 두 회사의 키는 따로 보관되어 모델을 바꿔도 다시 넣을 필요가 없습니다. 업스테이지 키는 개인 키로 쓸 수 없습니다.
  - 키는 이 웹앱의 서버 함수(`api/refine.js`)를 거쳐 해당 AI 회사로만 전달되고, 서버에 저장하거나 기록하지 않습니다.
  - 브라우저에는 기본적으로 탭을 닫을 때까지만 남습니다. '이 PC에 키 기억'을 켜면 이 브라우저에 계속 남으니 공용 PC에서는 켜지 마세요. '이 PC에서 모두 지우기'로 지울 수 있습니다.
  - GPT와 Claude는 각 회사의 공식 SDK(`openai`, `@anthropic-ai/sdk`, `package.json`에 명시)로 호출합니다. `ANTHROPIC_MODEL`을 `claude-opus-5`처럼 거절 시 재시도를 지원하는 모델로 바꾸면, 안전 정책으로 거절될 때 서버가 알맞은 다른 Claude 모델로 한 번 더 시도합니다(`fallbacks: "default"`).
- 목록에 보이는 모델 이름은 서버 설정(`UPSTAGE_MODEL`, `OPENAI_MODEL`, `ANTHROPIC_MODEL`)을 따라 바뀝니다.

Vercel 프로젝트의 Settings → Environment Variables에 넣는 값(넣은 뒤 다시 배포해야 적용):

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| `UPSTAGE_API_KEY` | 선택 | 학교(서버) 키. 없으면 개인 키로만 쓸 수 있음. 브라우저로 보내지 않음 |
| `ACCESS_CODE` | 권장 | 서버 키를 쓸 때 이 코드를 입력한 사람만 쓸 수 있음(주소를 아는 누구나 호출하는 것을 막음) |
| `UPSTAGE_MODEL` | 선택 | 기본값 `solar-pro4` |
| `UPSTAGE_REASONING_EFFORT` | 선택 | 기본값 `none`. 추론을 켜면 답을 내기 전에 토큰을 다 써서 빈 응답이 올 수 있음 |
| `OPENAI_MODEL` | 선택 | 개인 GPT 키로 쓸 모델. 기본값 `gpt-6-luna` |
| `ANTHROPIC_MODEL` | 선택 | 개인 Claude 키로 쓸 모델. 기본값 `claude-sonnet-5` |

설정이 적용됐는지는 `/api/refine` 주소를 열어 확인합니다. `enabled`는 서버 키, `requiresCode`는 접속 코드 적용 여부이고, 어느 배포인지 알 수 있게 환경·브랜치·커밋도 함께 보여 줍니다(비밀 값은 나오지 않음).

AI 회사로 보내는 항목(학교 키는 업스테이지, 개인 키는 OpenAI 또는 Anthropic): 관찰 메모(메모 속 학생 이름은 '학생'으로 바꿈), 단원, 학년, 반 공통 수업 내용, 교사가 지정한 수행 강도·문체·목표 분량, 교사가 직접 지정한 학생 유형. 개별 학생 탭에서는 여기에 학교급과 체크한 활동·강점이 더해집니다. 성명, 반/번호, 학생개인번호는 보내지 않습니다. 사용자가 전송 동의에 체크하고 버튼을 누를 때만 전송합니다.

AI에는 메모에 없는 사실을 만들지 않기, 신앙 평가 표현 쓰지 않기, 명사형 종결, 500자 이내 같은 규칙을 지시합니다. 그래도 결과는 반드시 메모와 비교해 확인해야 하며, 결과표에서 학생별로 원래 문장으로 되돌리거나 다시 다듬을 수 있습니다.

## 개인정보

- 저장한 메모에는 반/번호(또는 '학생' 열 값)만 남기고 성명은 저장하지 않습니다.
- 저장한 지 30일이 지난 메모는 자동으로 지워집니다.
- 공용 PC에서는 작업을 마친 뒤 상단의 '이 PC에서 모두 지우기'로 저장한 메모와 화면의 입력·생성 결과를 한 번에 지울 수 있습니다(직접 추가한 단원/수업 주제는 남음).
